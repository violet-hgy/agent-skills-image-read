# Output

```text
【识图场景】…

【元数据】源 / 整图像素 / scale / 参照系 / 工具；流水线=读图

【可视结构】…
【像素参数表】| 字段 | 值 | 实测/推导/猜测 |
【视觉参数表】…
【结构专表】或「不适用」
【需确认】
【差异 / 不确定】
【暂时猜测数值占用】或「无」
```

完成判定（强制）：有场景、有外框+border 行、有视觉表（text-extract 除外）、结构专表齐、无未声明猜测、未夹带写码。

缺任一关键区块标题（见 ImageRead 输出模板），视为“未执行完整 SOP”，**未完成禁止**进入写码/实现描述。

## 交付物（供 LLM 直接消费）

报告须 **自解释**，使未安装任何写图特化的 LLM 也能仅凭下表理解界面：

| 区块 | 作用 |
| --- | --- |
| 【可视结构】 | 人/模型快速建立 UI 树与层级 |
| 【像素参数表】 | 几何、间距、外框、border、radius（含实测/推导/猜测列） |
| 【视觉参数表】 | 色、字、透明度、圆角等可视项 |
| 【结构专表】 | 列表 itemSpacing、弹层分列、透明 pad 等场景专数 |

**禁止**在报告末尾夹带 QML/React/Swift 等实现代码；写码属于宿主特化或 LLM 自由发挥，不属于 ImageRead 输出。

报告最后必须追加一行结束语（原样）：

```text
【ImageRead完成，等待宿主消费报告；本阶段不写代码】
```

缺少该结束语：视为 Phase 1 未闭环完成。
