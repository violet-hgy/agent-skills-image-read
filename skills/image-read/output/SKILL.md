# Output

```text
【识图场景】…

【元数据】源=无损原图(默认) / 整图像素 / scale / 参照系 / 测图后端；流水线=读图

【元素清单】N — …
【元素清单表】| # | 短名 | 必测字段 | 状态=已测 |

【可视结构】…
【像素参数表】| 字段 | 值 | 实测/推导/猜测 |
【视觉参数表】…
【结构专表】或「不适用」

【测量完备性】清单N / 实测A / 推导B / 猜测C / 猜测占比=C/N
【需确认】或「无」
【差异 / 不确定】或「无」
【暂时猜测数值占用】或「无」
```

## 完成判定（强制）

1. 关键区块标题齐全（含【元素清单】【测量完备性】）  
2. 【元素清单表】无「待测」行；用户点名项均为「已测」  
3. 有外框+border 行、有视觉表（text-extract 除外）、结构专表齐  
4. 无未声明猜测；未夹带写码  
5. **猜测占比门控**：  
   - `page-layout` 或多元素（N≥3）：`C/N > 0.15` **或** `C > 3` → **未完成**  
   - 其它场景：`C > 3` 且多为可测几何 → **未完成**  
6. 可测几何标成「猜测」→ **未完成**（须重测）

缺任一项：

```text
【ImageRead未完成】缺少：<…>
请先补齐清单实测，再继续写 UI。
```

## 无损原图默认（禁止甩锅给开发）

默认开发提供的位图为**无损原图**。禁止因“位图有损/阴影模糊/信息不足”等**前置借口**：

- 少测清单项  
- 把可测几何改成猜测  
- 要求开发二次确认或“再发一张图再对齐”  

【需确认】仅用于：目标框无法唯一框定、asset 尺寸双源冲突、落点映射不唯一等**真缺信息**。

## 交付物

报告须自解释。**禁止**报告末尾夹带实现代码。

报告最后必须追加（原样）：

```text
【ImageRead完成，等待宿主消费报告；本阶段不写代码】
```

缺少该结束语：视为 Phase 1 未闭环。
