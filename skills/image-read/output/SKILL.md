## 完成判定（强制）

1. 关键区块标题齐全（含【测量范围】【元素清单】【测量完备性】）  
2. 【元素清单表】**范围内**无「待测」行；用户点名项均为「已测」  
3. **叶子门控**：  
   - `layout-only`：不要求叶子  
   - `named-extract`：包含树已列；纳入的基础叶子均有该类型【UI属性】；文字缺字号/字色或列表缺列宽/行高 → **未完成**；测了目标外兄弟 → **未完成**  
   - `full-page`：图上各容器叶子都测完  
   - `named-subtree` / `named-control`：点名块内叶子已测；**禁止**因没测范围外叶子判未完成  
4. 纳入的基础叶子有【UI属性】（可与像素/视觉表合并）。未纳入的叶子类型不测。  
4b. **分区对称**（`page-layout` / 多列）：… `named-extract` **跳过**本条。  
4c. **清单≠分区**：… `named-extract` 从属指向【包含关系】树上的父节点。  
4d. **图标**：纳入的图标叶子须标源与墨迹。  
4e. **字体颜色 / 字号**：纳入的文字叶子必列。  
4f. **列表**：纳入的列表叶子必列列宽、行高（能分列才分列）；不强制 scrollbar，除非该叶子在树里。  
4g. **按钮**：拆底面+文字；底面圆角/填色，文字走文字属性。  
4h. **参照系**：有框/列宽等几何属性时须完整；仅文字色也可标相对=父:叶子。  
5. 无未声明猜测；未夹带写码  
6. **猜测占比门控**（N = **范围内**清单行数）：  
   - `page-layout` 或多元素（N≥3）且非 `named-extract`：`C/N > 0.15` **或** `C > 3` → **未完成**  
   - 其它场景：`C > 3` 且多为可测几何 → **未完成**  
   - `named-extract`：C 只计命中维度却无法辨认的节点  
7. 可测几何标成「猜测」→ **未完成**（须重测）  
8. 控件级范围内同排分段粒被写成「单条轨道」而无粒级行 → **未完成**（`layout-only` / `named-extract` 按维度：列表内容必须拆行）

缺任一项：

```text
【ImageRead未完成】缺少：<…>
请先补齐清单实测（按【测量范围】颗粒度），再继续写 UI。
```

## 无损原图默认（禁止甩锅给开发）

默认开发提供的位图为**无损原图**。禁止因“位图有损/阴影模糊/信息不足”等**前置借口**：

- 少测**范围内应测项**（`layout-only` 漏容器；控件级漏叶子；`named-extract` 漏包含树中命中维度的节点——**不是**去补未点名维度）  
- 把可测几何改成猜测  
- 要求开发二次确认或“再发一张图再对齐”  

【需确认】仅用于：目标框无法唯一框定、asset 尺寸双源冲突、落点映射不唯一等**真缺信息**。

## `named-extract` 报告（可视元素主线）

最低交付：【包含关系】拆到基础叶子 + 每片叶子【UI属性】。

```text
【识图场景】named-extract — 确认弹窗
【测量范围】named-extract
【提取目标】confirmPanel
【提取维度】文字
【包含关系】
confirmPanel
├─ title          ← 文字
├─ subtitle       ← 文字
└─ buttonRow
   ├─ btnCancel
   │  ├─ fill     ← 色块
   │  └─ label    ← 文字
   └─ btnOK
      ├─ fill
      └─ label
【UI属性】
title: 原文=… / 墨迹高=… / 字号=未稳定 / 字色=#… / 字重=Bold / 对齐=水平居中
subtitle: …
btnCancel/label: 原文=取消 / 字色=#… / …
btnCancel/fill: 外框=… / 填色=#… / 圆角=…   （若维度只纳入文字则 fill 可不列）
【测量完备性】文字叶子均有字号或墨迹+字色
【ImageRead完成，等待宿主消费报告；本阶段不写代码】
```

维度=列表时列表叶子必须有列宽、行高；行内文字走文字 UI 属性。
