## 完成判定（强制）

1. 关键区块标题齐全（含【测量范围】【元素清单】【测量完备性】）  
2. 【元素清单表】**范围内**无「待测」行；用户点名项均为「已测」  
3. **叶子门控**：  
   - `layout-only`：**不要求**叶子；有叶子行也不当完成条件  
   - `full-page`：图上各容器叶子都测完  
   - `named-subtree` / `named-control`：点名块内叶子已测；**禁止**因没测范围外叶子判未完成  
4. 有外框+border 行、有视觉表（text-extract 除外）、结构专表齐  
4c. **清单≠分区**：每条清单须有从属路径且落在分区树已有节点上。禁止因「单独测过 / 有独立高度」把内部项升成新列或新一级卡。缺从属或从属悬空 → **未完成**  
5. 无未声明猜测；未夹带写码  
6. **猜测占比门控**（N = **范围内**清单行数）：  
   - `page-layout` 或多元素（N≥3）：`C/N > 0.15` **或** `C > 3` → **未完成**  
   - 其它场景：`C > 3` 且多为可测几何 → **未完成**  
7. 可测几何标成「猜测」→ **未完成**（须重测）  
8. 控件级范围内同排分段粒被写成「单条轨道」而无粒级行 → **未完成**（`layout-only` 不适用本条）

缺任一项：

```text
【ImageRead未完成】缺少：<…>
请先补齐清单实测（按【测量范围】颗粒度），再继续写 UI。
```

## 无损原图默认（禁止甩锅给开发）

默认开发提供的位图为**无损原图**。禁止因“位图有损/阴影模糊/信息不足”等**前置借口**：

- 少测**范围内应测项**（`layout-only` 漏容器；控件级漏叶子）  
- 把可测几何改成猜测  
- 要求开发二次确认或“再发一张图再对齐”  

【需确认】仅用于：目标框无法唯一框定、asset 尺寸双源冲突、落点映射不唯一等**真缺信息**。
