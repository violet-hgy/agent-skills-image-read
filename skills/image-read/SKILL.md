# ImageRead

## 定位

```text
ImageRead（本包）  →  结构化像素报告（可视参数表）  →  【ImageRead完成…】→ 结束
```

**只读图、只出数。** 主线是描述可视元素（包含树 → 基础可视叶子 → 该叶子的 UI 属性），不是先按「只要文案」把字号/字色省掉。

本包能力边界：

- **做**：场景分流、测几何/视觉、出对用户可见的参数报告  
- **不做**：写 UI / 改工程文件、推断 GUI 语言、调度写码 skill、宣称一次对齐完成、落资源清单、改 Figma  

后续是否写码、用哪个写码 skill，**与本包无关**（由其它 skill / 宿主 SOP 决定）。

## 与「一次对齐」

若用户要一次对齐 / 按图实现：本包仍只负责 **识图前置**——先交出完整参数报告。  
写码与自校 **不是** ImageRead 步骤；禁止因「要对齐」在本包内改 UI 或跳过报告。

## 自动触发（Agent 自动挂载）

**位图** = 栅格图：PNG、JPEG/JPG、WebP、GIF、BMP、TIFF，以及截图/聊天附图（格式不论）。不含 SVG 矢量源、不含 Figma 节点树。

**位图默认 = 无损原图。** 禁止以“有损/信息不足/要二次精调”为由少测或要求开发口头二次确认。

**命中任一且像素来自位图时，必须先 Read 并执行本 skill，再报尺寸或进入任何写 UI：**

- 用户附图、控件切图、整页截图（PNG/JPEG/WebP 等）
- 意图：按图还原、像素对齐、量尺寸、取特定元素、设计评审、从图提取参数、对齐稿面（且源是图）
- 对话要求【识图场景】、一次对齐（仍先出报告）或对 **位图** 出像素表 / 文案表

**取特定元素在 classify 定范围，不跳过本包。** 范围=`named-extract`：按可视包含拆到**基础可视元素**，再罗列该叶子的 UI 属性（文字→字号/字色…；列表→列宽/行高…）。【提取维度】只决定纳入树的哪几支，不省略已纳入叶子的属性。禁止测目标外兄弟。细则见 `./classify/SKILL.md`。

**硬门控：** 有位图要报几何 / 取图内元素 / 随后可能写 UI → **禁止**跳过本 skill 直接写尺寸或「大约」填数。  
**报告必须对用户可见：** 写在对用户的回复正文里，禁止只在思考中“做过测量”、禁止先改文件再补报告。

**防漏触发：** 用户要从图取色 / 字重 / 圆角 / 间距 / 切图 / 文案时，不得以「只改样式 / 已有组件 / 只要文案」为由跳过本 skill。

**禁止私自测图冒充门控：** Agent 私跑 Pillow/脚本/终端采数 **不能**代替对用户可见的【像素参数表】与结束语；无完整报告 = **未走 skill**。

### 明确无效的借口（出现即流程失败）

下列理由**一律不能**用来跳过或延后【像素参数表】：

- 「尽快可见效果 / 先把 UI 和按钮做出来再补参数」  
- 「先搭骨架 / 先能跑 / 先给个近似界面」  
- 「参数以后再对齐 / 报告可省略」  
- 「用户急着看效果所以先写码」  
- 「大致看着像就行，不必输出参数表」  
- 「只改已有组件色值/字重/圆角，不算需要识图」  
- 「我已经用脚本/Pillow 量过了，不必出参数表」

命中任一条 → 立刻输出【流程回退】，停止改 UI 文件，先补完整 ImageRead 报告。

**不触发：**

- **纯 Figma**（仅链接/`node-id`，无用户位图）：用 Figma MCP 节点 px，**不要**对本 skill / 导出 PNG 再量  
- 无图、仅改已知文案/色/逻辑、纯协议或后端任务  

## 取特定元素（仍走本包 · 范围在 classify）

附图要取图上某块时：**必须跑 ImageRead**。主线：

1. **提取目标**：点名或截图主体（bbox 根）
2. **包含关系**：拆到基础可视元素（文字、色块、列表、图标…）
3. **提取维度**：纳入树的哪几支（开放）。例：只要文字支、只要列表支
4. **UI 属性**：每个基础叶子按类型罗列（文字：原文/字号/字色/字重/对齐；列表：列宽/行高…）

容器节点只表达包含；叶子必须有 UI 属性表。目标外兄弟不进清单。

**【识图场景】码（classify 产出）：** `named-extract`、`dialog-sheet`、`delegate-row`、`control-full`、`page-layout`、`showcase-align`、`overlay-badge`、`visual-tweak`、`measure-only`。细则见 `./classify/SKILL.md`。

## 嵌套结构

```text
image-read/
├── SKILL.md
├── classify/ gates/ geometry/ structure/ visual/ output/
```

## 调度顺序（强制 · 仅识图）

1. `./classify/SKILL.md` → 场景/范围/（`named-extract`）提取目标·包含关系·提取维度·元素清单  
2. 叶子 UI 属性含色或尺寸 → `./gates/SKILL.md`。无可用后端 →【ImageRead环境未就绪】并结束。  
3. `./structure/SKILL.md` → `./geometry/SKILL.md`（框、列宽、行高等几何属性）  
4. `./visual/SKILL.md`（基础叶子的字号/字色/填色等；**已纳入的文字/列表叶子禁止只抄原文**）  
5. `./output/SKILL.md` → 报告（含各叶子【UI属性】）  
6. **同轮删除本轮新建的测图临时脚本**（见下节）；未删不得输出完成结束语

**需要采像素且 gates 未 OK 时本包职责已终止。** 基础叶子的字色/框尺寸属于采像素。失败退出前同样要删已创建的临时 py。

## 测图临时脚本（强制 · 同轮删除）

Python 仅为测量运行时。本轮为采像素而**新建**的一次性脚本（常见 `.cursor/tmp_measure_*.py`、仓库根 `tmp_*.py`、随手 `Write` 的测图 py）**不是工程文件**。

```text
优先不落盘（python -c / stdin / 本包 scripts/）
  → 必须落盘：系统临时目录，或 `.cursor/tmp_measure_<短名>.py`
  → 禁止写入 qml/ src/ res/ 等源码目录
  → 出数后立刻 Delete（环境 FAIL / 中途失败同样删）
  → 再输出【ImageRead完成…】
```

- **未删临时测图 py = 本包未闭环**；禁止完成结束语，禁止留给「稍后 / 提交时再清」
- **禁止**把测图脚本当工程文件提交
- 环境探测只复用本包 `scripts/`（如 `probe-measure-env.*`），不要另留仓库内一次性 py

## 交付协议（强制 · 只出报告）

### 本轮只产出识图报告

当本 skill 被触发时：先 **classify**（定范围 / 提取目标 / 维度 / 包含关系）。需要采像素时再跑 **gates**。环境 FAIL 时首次输出只能是【ImageRead环境未就绪】，**不是**完整参数表，也**不是** UI。

classify 之后，**本轮首次实质性输出必须是 ImageRead 报告**，且只允许：

- 按【测量范围】测清单；`layout-only` 只测容器骨架；`named-extract` 拆到基础叶子并列出各叶子 UI 属性  
- 输出【识图场景】【测量范围】【元素清单】（`named-extract` 必有【包含关系】【提取维度】及叶子【UI属性】）  
- 【测量完备性】按范围+维度达标；猜测仅限不可测单字段  
- 标注【需确认】仅真缺信息（禁止无损原图借口）  

**本阶段禁止：**

- 任何 UI 实现代码（含 `Write`/`StrReplace`/创建源文件等改工程动作）  
- 任何“先给你一个可见界面/近似还原/尽快可见效果”的方案或借口  
- 任何绕过参数表的布局建议  
- 把 SKILL 总说明、口头摘要当作“已完成报告”  
- 只在内部思考里列尺寸、不对用户输出【像素参数表】等区块  
- 点名或调度写码 skill、在本包内开始落码  

**对用户可见的最低交付（缺一不可）**，并以结束语收束：

```text
【ImageRead完成，等待宿主消费报告；本阶段不写代码】
```

没有这条结束语 = 本包未闭环。完整报告之后，**本 skill 即结束**。  
若本轮 `Write` 过测图临时脚本，结束语前必须已 `Delete`。

### 报告完成门控

若本轮目标包含“从图实现 / 报几何 / 改布局”，在交付前：

- **gates FAIL**：只输出【ImageRead环境未就绪】并停止  
- **gates OK**：须先有完整报告，且含【测量范围】【元素清单】【测量完备性】且门控通过  

报告必须至少包含下列区块标题（原样）：

- `【识图场景】`
- `【测量范围】`
- `【元素清单】`
- `【测量完备性】`
- `【需确认】`
- `【差异 / 不确定】`
- `【暂时猜测数值占用】` 或 `无`

像素路径另须：`【参照系】`、`【像素参数表】`、`【视觉参数表】`、`【结构专表】` 或 `不适用`。

`named-extract` 另须：`【提取目标】`、`【提取维度】`、`【包含关系】`、各基础叶子的 `【UI属性】`。禁止测目标外兄弟；禁止文字叶子只抄原文、列表叶子只抄行文案。

未包含任一项或完备性门控失败：

```text
【ImageRead未完成】缺少：<区块名列表或完备性原因>
请先补齐清单实测。
```

若在完整报告前已经输出过实现代码/方案，或曾以“尽快可见效果”为由跳过参数表，视为**流程失败**：

```text
【流程回退】已进入实现但未先完成 ImageRead 报告（或借口跳过参数表）。
停止一切 UI 改动；先补完整报告（含【像素参数表】）。
```

禁止把“本 SKILL.md 的总说明”当作完成报告。  
禁止“边写码边补测 / 写完再补报告”。

## 硬规则

- 禁止未读图写参数表；禁止「大约」当实测  
- 猜测必须【暂时猜测数值占用】；**可测几何禁止猜测**  
- 有图必须先有【识图场景】+【测量范围】+【元素清单】  
- `layout-only`：测完容器外框/分栏/gap 即可，禁止拆内部控件  
- `named-extract`：清单=目标内纳入的基础叶子；每片叶子须有该类型 UI 属性；禁止测目标外兄弟  
- 控件级（`full-page` / `named-subtree` / `named-control`）：范围内含叶子；未测完 / 只测容器外框 → 报告未完成  
- 禁止因整页截图就展开范围外叶子；未测范围外叶子不算失败  
- 阴影只记不当描边  
- 设计 px + 注明 scale；用户口头 px 优先  
- **默认无损原图**；禁止据此要求开发二次确认  
- **禁止**本包识图流水线内写码或调度写码 skill  
- Python 未就绪，或无任何可用测图后端：**禁止**整表估算  
- 当前后端失败：先自动修，仍失败则换其它可用后端实测；禁止目测估算  
- **不强制 cv2**；【元数据】写明实际使用的测图后端  
- **本轮新建的测图临时 `.py` 必须同轮删除**；未删 = 未闭环；禁止提交、禁止写入工程源目录
