# 内置布局模式

供 skeleton、composition 与关键几何分析使用。按结构特征匹配，可组合；名称是分析标签，不确认具体框架或布局引擎。
每个匹配项都结合实际证据描述方向、层级、对齐、间距、尺寸关系、滚动与覆盖；缺少的部分不补出。

## 页面与窗口骨架

### application-shell：客户端 / 后台应用壳
- 特征：标题条、应用页头、侧栏、主区、状态栏或底栏形成稳定外围。
- 展开：宿主窗口 chrome → 应用区域；应用区域再分导航、工具、内容和状态区域。
- 重点：系统标题栏与应用内页头分开；全局操作与页面操作分开；主区独立滚动边界。
- 易错：把窗口边框当页面 padding；把底部状态条当操作按钮行；仅凭位置确认吸顶。

### sidebar-detail：侧栏 + 详情
- 特征：一侧分类/导航，另一侧内容或详情。
- 展开：侧栏 → 导航分组/项目；详情 → 标题/工具区/内容区。
- 重点：侧栏宽度、分隔线、选中项、详情内边距；两侧是否分别有可见滚动。
- 易错：将普通内容列误判成导航；把单视口宽度直接当固定宽度规则。

### master-detail：主列表 + 详情
- 特征：对象列表与当前对象详情并排或分上下区。
- 展开：列表区 → 搜索/过滤/行模板；详情区 → 对象标题/属性/操作。
- 重点：选中行与详情的关联证据、空详情占位、两区工具归属。
- 易错：将两个独立列表强行解释为联动；凭截图确认点击加载机制。

### split-workspace：双栏 / 三栏工作区
- 特征：资源树或列表、中央编辑/预览、属性检查器等多面板。
- 展开：全局工具栏 → 各面板 → 面板内标题/页签/内容；有底部控制台时单列。
- 重点：主次宽度、面板分隔、折叠/拖动把手的可见线索、面板内滚动。
- 易错：每个测量项都升成一列；把分隔线直接认定为可拖动分栏器。

### header-content-footer：页头 + 主体 + 页脚
- 特征：纵向大区块；常见内容页、详情页、客户端配置页。
- 展开：页头内部标题/导航/操作；主体分节；页脚说明或操作。
- 重点：内容最大宽度、居中关系、各区外距；有证据才确认页脚固定。
- 易错：把内容末尾操作区当窗口固定底栏。

## 内容组织

### stack-row：纵向堆叠 / 横向行
- 特征：同一方向排列的区域或控件，可存在嵌套。
- 展开：组 → 子项；分别描述主轴间距与交叉轴对齐。
- 重点：间距是否一致、文字基线与几何居中是否不同、首末外距。
- 易错：把 gap 与 padding 混为一个 spacing；把视觉横排直接称 CSS flex。

### grid-cards：规则网格 / 卡片矩阵
- 特征：多行多列、行列基准对齐的卡片或按钮。
- 展开：网格容器 → 单元模板 → 实例差异。
- 重点：可见行列数、等宽/不等宽、行列 gap、跨格项、内容高度差异。
- 易错：从一个宽度推断响应式断点；假定所有卡片同高或可点击。

### flow-wrap：流式换行 / 标签流
- 特征：项目宽度随内容变化，同一行末尾后换行。
- 展开：流容器 → 项目模板；记录行内间距、行距及当前换行结果。
- 重点：自然内容宽度、基线、截断、容器边界。
- 易错：误判为严格列网格；将截图换行位置当成固定分组。

### masonry：错列瀑布布局
- 特征：多列项目高度不同，同列纵向连续，跨列行基线不齐。
- 展开：可见列/项目及局部上下邻接关系。
- 重点：列宽、列间距、项目顺序是否有证据；区分普通不等高卡片网格。
- 易错：仅凭少量不齐边缘确认瀑布算法；猜测不可见项目顺序。

### form-layout：表单布局
- 特征：标签、输入区、辅助说明与校验反馈形成重复字段。
- 展开：分组 → 字段行/字段列 → 标签/控件/说明/反馈；操作区独立。
- 重点：顶置/左置/内嵌标签、标签宽度对齐、单列/多列、必填与错误标记。
- 易错：将 placeholder 当持久标签；把提示信息当输入值。

### list-table-tree：列表 / 表格 / 树
- 特征：同构行、多列字段或递进缩进。
- 展开：工具区、表头（若有）、视口、行模板、分页/汇总；树另列层级与展开指示器。
- 重点：列对齐、行密度、缩进、选中/分组/汇总行差异、行操作、可见滚动条。
- 易错：把所有重复文本都称表格；凭缩进断言真实数据父子关系。

### reading-sections：文档 / 内容分节
- 特征：标题、段落、媒体、引用、目录和相关内容分节。
- 展开：正文主列、目录/辅助侧栏、章节层级和嵌入媒体。
- 重点：阅读宽度、文字层级、章节间距；目录与正文关联只按证据描述。
- 易错：每个段落当卡片；仅凭侧栏位置断言目录滚动跟随。

## 导航与浮层布局

### tabbed-regions：页签分区
- 特征：标签条 + 当前内容区，可带关闭、数量或图标。
- 展开：页签条 → 页签模板/选中差异；内容面板单列。
- 重点：页签指示器、与内容区边界、工具按钮是否属于页签条。
- 易错：把筛选胶囊当页面导航；编造未展示页签内容。

### overlay-anchor：锚定浮层 / 模态面板
- 特征：覆盖主内容的菜单、提示、弹窗、抽屉、通知等。
- 展开：背景上下文、遮罩（有则）、面板、面板内区域；另记触发器或锚点。
- 重点：锚定边、遮挡、层级、面板内 padding、箭头与触发器距离。
- 易错：以空间包含决定语义父级；把遮罩尺寸算入面板尺寸。

### mobile-compact：紧凑客户端 / 窄屏前端
- 特征：顶部导航、单列主体、底部导航或浮动操作。
- 展开：顶部区域、主体、底部区域及独立浮层。
- 重点：可见安全留白、触达区域、内容与底栏重叠；只报告实际视口。
- 易错：无设备证据时指定平台安全区值；编造从桌面到窄屏的断点规则。

## 使用边界

滚动、吸顶、固定、拖动、内容自适应和响应式行为需要源属性、多个视口或实际交互证据。
只有单张截图时先描述当前排列关系，并将可能机制标为推断。
遇到不能由上述模式及其组合解释的布局，记录缺口后进入 [external-research.md](external-research.md)。
