# 内置控件模式

供 composition / style 分析使用。控件角色与视觉组成分别保留，不要求把所有控件强制拆成像素叶子。
以下组成是检查候选项，只有参考中实际存在才纳入；外观相似但角色不能确认时保留候选名称。
每个控件按请求记录：类型、角色、父容器、排列与尺寸关系、样式、可见状态、证据。
不要依据惯例补出 hover、pressed、键盘交互、数据行为或隐藏面板。

## 操作与选择

### button：按钮 / 图标按钮 / 分裂按钮
- 组成：点击面、标签、前后图标；分裂按钮另有分隔和菜单触发区。
- 样式：主/次/文字/危险外观、填色、描边、圆角、图文间距、视觉尺寸与热区区别。
- 状态：图中可见的默认、禁用、加载、焦点或按压表现。
- 易错：按钮文字与底面分开后丢失控件身份；把按钮外框自动当准确点击热区。

### check-radio-toggle：复选 / 单选 / 开关
- 组成：标记框或轨道/拇指、标签、辅助说明、分组标题（若有）。
- 样式：标记形态、选中差异、标签对齐、轨道与拇指尺寸关系。
- 状态：选中、未选中、混合态、禁用等，仅记可见项。
- 易错：只凭圆形外观确认单选；将开关状态等同业务已保存状态。

### segment-chip：分段选择 / Chip / Tag
- 组成：组容器、选项、标签、图标/关闭柄/计数（若有）。
- 样式：共用轨道与独立底面、选中强调、粒间 gap、单粒圆角、内容宽度。
- 易错：把分段整条背景当唯一控件；把展示标签当可点筛选；假定单选或多选行为。

### slider-stepper：数值滑条 / 步进器
- 组成：轨道、已填充段、拇指、刻度/数值、加减控件（按实际）。
- 样式：轨道厚度、拇指形态、标签位置、当前值强调。
- 易错：与滚动条混淆；仅凭拇指位置推断数值范围或步长。

## 输入与编辑

### text-input：输入框 / 文本域 / 搜索框
- 组成：标签、输入面、值或 placeholder、前后缀、清除/搜索按钮、说明和错误反馈。
- 样式：高度、内边距、圆角、描边、文本层级、多行与截断。
- 易错：placeholder 当实际内容；边框强调自动认定为焦点而不考虑错误/选中状态。

### select-combo：下拉选择 / 可编辑组合框 / 级联选择
- 组成：标签、当前值、触发器、展开指示；可见面板再拆搜索、选项、分组和滚动。
- 样式：触发区与面板的边框/圆角/宽度关系，选项行高与选中标记。
- 易错：补出未展开选项；见箭头就认定是可编辑 ComboBox。

### date-time-picker：日期 / 时间 / 范围选择
- 组成：输入/触发区；可见面板中的月份导航、星期头、日期格、时间列、操作区。
- 样式：当前日与选中日、范围首尾与中间填色、不可选项的可见差异。
- 易错：将淡色日期直接认定不可选；由一个日期格推断周起始和全部禁用规则。

### upload-editor：上传 / 富文本编辑
- 组成：拖放区/选择按钮/文件条目/进度；编辑器另列工具栏、编辑面、计数或状态区。
- 样式：边界、工具组分隔、内容与提示层级、附件模板。
- 易错：拖放提示并不能证明实际拖放已实现；工具图标不证明快捷键或格式行为。

## 导航与菜单

### navigation：导航项 / 页签 / 面包屑 / 分页
- 组成：组、项、标签、图标、指示器、计数、折叠或关闭控件（按实际）。
- 样式：选中强调、层级缩进、分隔、页签下划线、页码密度。
- 易错：把相同外观的过滤器当路由导航；推断未展示页数或目标地址。

### menu-popover-tooltip：菜单 / 弹出面板 / 提示
- 组成：锚定或触发上下文、面板、菜单组/项目/分隔/快捷键提示/子菜单箭头。
- 样式：面板层级、阴影、内距、行高、图标列和标签列对齐。
- 易错：说明性 tooltip 当操作菜单；静态快捷键文案当已验证键盘功能。

## 数据与容器

### list-row：列表行 / 导航行
- 组成：前置图标/头像/选择标记、主次文本、数值/状态、尾部操作；按实际选取。
- 样式：行高、文字层级、列对齐、分隔线、选中面；重复模板 + 例外。
- 易错：行内按钮归入行本身后遗漏；将所有行视为相同高度。

### table：数据表格
- 组成：表头、字段列、数据行、排序/筛选提示、选择列、行操作、汇总与分页（按实际）。
- 样式：列宽、行高、表头差异、斑马纹、单元格对齐、截断、分隔线。
- 易错：图标存在就确认排序/固定列可用；把表头与工具栏混成一行。

### tree：树 / 树表
- 组成：层级缩进、展开指示、节点图标、标签、选择标记和节点操作。
- 样式：层级间距、连接线、行高、选中与展开表现。
- 易错：将展开态等同已加载全部后代；对不可见节点计数。

### card-panel-group：卡片 / 面板 / 分组 / 折叠面板
- 组成：容器面、标题、说明、工具区、内容、页脚；可见折叠触发器另记。
- 样式：padding、分区 gap、圆角、描边、阴影、标题层级。
- 易错：容器只写“包含”而漏样式；每项有外框就新建独立卡片。

### scrollbar：滚动条
- 组成：轨道、滑块、端部按钮（有则）。
- 样式：方向、宽度/高度、滑块长度、内容到条间距、条到视口边距、轨道与滑块色。
- 易错：与数值滑条混用；图中不可见就认定页面不可滚动。

## 反馈与展示

### dialog-drawer：对话框 / 抽屉
- 组成：遮罩（若有）、面板、标题/关闭、正文、操作区；正文可以再含表单或列表。
- 样式：面板锚定、宽高关系、正文滚动、操作区布局、主次按钮。
- 易错：面板和遮罩合测；认为所有浮层都模态；补出点击遮罩关闭行为。

### feedback：通知 / 警告 / 进度 / 骨架屏 / 空状态
- 组成：状态图标、标题、说明、进度轨道/填充、占位骨架、操作或关闭按钮（按实际）。
- 样式：状态强调、层级、密度、占位形状、阻塞或覆盖的可见关系。
- 易错：从进度长度推断准确百分比；把骨架屏当最终内容；将颜色直接认定为成功/错误语义。

### media-status：图片 / 图标 / 头像 / Badge / 数据图表
- 组成：显示容器、可见内容、边框、角标或状态点；图表另列标题、绘图区、轴/图例/提示（有则）。
- 样式：裁切、宽高比、墨迹与外框、文字层级、系列区分、图例位置。
- 易错：截图中反推出原始图片透明边距；根据曲线外形编造数据；把轴标签当控件。

## 未覆盖控件

先检查能否用上述模式组合，例如带搜索的下拉 = 输入框 + 选项列表 + 浮层。
若存在新的语义或空间组织机制且内置规则不足，记录缺口后按 [external-research.md](external-research.md) 检索。
