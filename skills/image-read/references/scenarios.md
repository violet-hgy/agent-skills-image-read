# 内置组合场景

在布局与控件规则之上组织分析。以下是检查路径，不是每个场景必含的组件清单。
客户端与前端共享 UI 模型；平台只作为上下文，不根据外观自动认定技术栈。

## 客户端与工作区

### 设置 / 偏好 / 设备配置
- 骨架：分类导航（有则）→ 分组详情 → 操作/状态区。
- 展开：组标题与说明、标签-控件行、依赖或禁用的可见表现、分组间距。
- 重点：同列字段对齐、辅助文案层级、滑条/开关/分段/下拉区别、主次操作。
- 未知边界：即时生效或保存后生效、隐藏依赖关系，不靠惯例确定。

### 编辑器 / IDE / 设计工具
- 骨架：全局菜单/工具 → 资源面板 + 编辑/预览区 + 检查器 → 状态/控制台。
- 展开：面板页签、工具组、树节点、编辑视口、选择对象的可见属性。
- 重点：全局与面板局部操作归属，嵌套分栏、覆盖工具、不同滚动区。
- 未知边界：拖动停靠、快捷键、缩放机制和选择联动需要证据。

### 文件 / 资源 / 媒体管理
- 骨架：位置/路径与工具区 → 分类树/筛选 + 列表/缩略图 → 预览/详情（有则）。
- 展开：路径层级、对象条目模板、状态/选择标记、行内或批量操作。
- 重点：网格与列表视图差异、预览框与原资源尺寸区别、可见排序提示。
- 未知边界：文件真实路径、拖放、批处理或上传行为。

### 播放 / 监控 / 控制面板
- 骨架：主要展示区 → 控制工具 → 信息/日志/状态区。
- 展开：播放/控制按钮、时间轴或数值滑条、数据卡、告警、可见模式选择。
- 重点：时间进度与音量/数值滑条区别、叠加控件、展示内容和交互控件边界。
- 未知边界：实时刷新、硬件能力、数据精度、不可见状态。

## 前端页面与业务界面

### 后台列表 / 数据管理
- 骨架：应用壳 → 面包屑/标题 → 筛选与批量工具 → 数据视口 → 分页/汇总。
- 展开：筛选字段、表头、行模板、行操作、选择列；仅列实际可见项。
- 重点：过滤与全局搜索区别、表格列对齐、表头/工具区分隔、可见滚动条。
- 未知边界：服务端分页、排序规则、权限与数据总量。

### 仪表盘 / 数据概览
- 骨架：标题/时间筛选 → 指标卡 → 图表/趋势 → 明细区。
- 展开：卡片标题/值/单位/变化量，图表绘图区/图例，重复卡片模板。
- 重点：网格跨度、对齐、信息层级、可视化与操作控件区别。
- 未知边界：真实数据、计算公式、图表交互和刷新频率。

### 表单 / 创建编辑 / 分步流程
- 骨架：标题与说明 → 分组字段 → 校验/摘要 → 操作区；步骤条有则单列。
- 展开：标签、输入/选择、辅助说明、错误反馈、必填提示、步骤当前态。
- 重点：字段分组、单/多列、标签对齐、说明归属、主次操作。
- 未知边界：未展示的步骤、验证时机、提交接口和必填约束。

### 详情 / 个人资料 / 商品
- 骨架：对象概要/媒体 → 属性与正文 → 关联内容/操作。
- 展开：标题、状态、主次信息、属性组、媒体、操作组；页签有则展开可见面板。
- 重点：信息层级、标签和值的对应、主展示与缩略图关系、内容分节。
- 未知边界：库存、价格规则、可操作权限等业务事实。

### 登录 / 注册 / 找回
- 骨架：品牌/说明区 + 身份输入区 + 操作/辅助链接；背景展示按实际。
- 展开：标识、密码或验证码输入、同意项、主操作、反馈。
- 重点：placeholder 与标签区别、输入后缀、错误反馈与辅助链接层级。
- 未知边界：认证协议、密码规则、验证码发送时机和登录行为。

### 内容 / 营销 / 搜索结果
- 骨架：导航 → 主视觉或标题 → 正文/结果分区 → 行动区/页脚。
- 展开：标题层级、媒体、卡片/结果行模板、筛选/目录（有则）。
- 重点：阅读宽度、分节间距、视觉焦点、按钮与链接、展示图片的裁切。
- 未知边界：锚点跳转、SEO、懒加载、窄屏重排。

### 对话 / 动态 / 通知流
- 骨架：会话/过滤侧栏（有则）→ 消息视口 → 输入/操作区。
- 展开：消息/事件模板、头像、时间、状态、附件、日期分隔、输入工具。
- 重点：左右消息对齐、同组间距、长文本换行、附件与气泡边界。
- 未知边界：已读协议、实时连接、发送状态转换或不可见历史。

### 看板 / 日历 / 时间线
- 骨架：工具与筛选 → 泳道/时间格/事件轴 → 事件或任务卡。
- 展开：列/时间标题、可见卡片模板、分组与状态标记。
- 重点：行列跨度、时间/空间坐标关系、重叠项目、局部滚动。
- 未知边界：拖拽、排期冲突规则、时间精度或隐藏事件。

## 跨场景组合

### 弹窗 / 抽屉 / 底部面板
- 展开：背景上下文、遮罩、面板、标题、正文、操作；正文复用表单/列表规则。
- 重点：面板锚定和层级、局部滚动、与背景的覆盖关系。
- 未知边界：模态性、关闭方式、焦点限制；无证据时不确认。

### 菜单 / 角标 / 浮动工具
- 展开：触发或归属对象、浮层面、项目模板、状态或操作。
- 重点：外距与内距、锚点、箭头、阴影与描边区别。
- 未知边界：出现时机、消失机制、是否跟随滚动。

### 资源展示 / 资源比较（兼容 showcase-align、asset-compare）
- 展开：展示容器、资源显示框、墨迹框；独立资源可另量透明边距。
- 重点：宽高比、缩放、裁切、对齐锚点；双源差异保留，不擅自选择。
- 未知边界：截图中原始资源外框、alpha、原始尺寸。

## 缺口处理

场景不在此名单中时，先尝试已有布局与控件组合。陌生业务场景不等于新的 UI 模式。
确有未覆盖的布局或控件机制时，按 [external-research.md](external-research.md) 针对该部分检索，继续完成已覆盖部分。
