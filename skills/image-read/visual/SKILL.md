# Visual

主线：基础可视叶子的 **UI 属性**。`named-extract` 对已纳入的文字/列表/色块叶子必须出属性，禁止只抄原文。未纳入的叶子类型不测。

禁止只出几何。控件级范围（`full-page` / `named-subtree` / `named-control`）须覆盖并能稳定写入【视觉参数表】：

- 背景 / 前景 / 透明度  
- 字号 / 字重（含是否加粗）  
- **字体颜色**（见下 · 不一致时必须分角色罗列）  
- **列表滚动条颜色**（见下 · 图上可见则强制）  
- **按钮/可点控件圆角**（见下 · 按控件分列，禁止整页一个 radius）  
- 描边色 + 宽  
- **图标色**（能稳定读到时）  
- **图标几何**（见下 · 分两种源）

## 字号 vs 墨迹高度（强制 · 控件级）

位图上量到的**文字墨迹外接高**（可见笔画盒子）**不等于** `font.pixelSize` / 设计字号。

| 量到的 | 含义 | 能否直接当字号落码 |
| --- | --- | --- |
| 文字**墨迹** H（或 W） | 抗锯齿后可见笔画外接盒 | **否** |
| **字号**（设计 px） | `pixelSize` / 主题 Fonts 档 | 须另有依据（稿注、同页已知 Fonts、Figma text style、产品约定） |

硬规则：

1. 【视觉参数表】有文案时：字号与墨迹**分列**（或明确写「字号未从墨迹推断」）；禁止只报一个「文字高 xx」却落成 `font.pixelSize: xx`。  
2. **禁止**把墨迹高直接写成字号（即使数值接近，如墨迹 11～12、字号实为 14）。  
3. 仅能量到墨迹、字号无依据 → 字号标 **未稳定/待确认**，入【差异】；落码用同页已有 `Fonts.*` 或问用户，**禁止**用墨迹值冒充字号。  
4. 字重（Regular / Medium / Bold）另测或对照稿面，与字号分列。  
5. `layout-only`：不要求字号。  
6. `named-extract` 已纳入的**文字叶子**：必须列字号或墨迹高（与字号分列）；未稳定标【差异】，禁止省略。

自检口诀：**墨迹是看见多高，字号是设多大——两回事。**

## 字体颜色（强制 · 控件级）

范围内可见文案须采样文字色（设计 px 下采样 hex/主题映射前的实测色）。

| 情况 | 要求 |
| --- | --- |
| 范围内文字色**一致** | 可一行：`字体颜色 #RRGGBB（范围内一致）` |
| 范围内文字色**不一致** | **必须分角色/短名罗列**，禁止用一个「前景色」概括 |

不一致时的罗列格式（示例，按实图增删）：

```text
字体颜色：
- 标题 #……
- 正文/说明 #……
- 次要/弱化 #……
- 强调/链接 #……
- 选中态文案 #……
- 禁用态文案 #……（图中可见才列）
```

硬规则：

- 「前景」≠ 字体颜色：面板/卡片前景填色与**文字色**分列；文字色用 **字体颜色** 标签。  
- 同卡内标题与正文色不同、选中与未选中胶囊字色不同、主按钮与次按钮字色不同 → 一律分列。  
- 只写一个笼统前景/字色而图上明显多色 → 报告未完成。  
- 未稳定读到（抗锯齿采样抖）→ 标未稳定并入【差异】，禁止猜。  
- `layout-only`：不要求字体颜色。  
- `named-extract` 已纳入的**文字叶子**：必须列字色。

## 列表滚动条颜色与间距（强制 · 控件级）

`layout-only` / `named-extract`（维度不是滚动条几何/色）：**跳过本节**。

范围内列表 / `ScrollView` / 可滚面板旁，图上**看得见**竖或横滚动条（滑动条）时：

| 必测 | 要求 |
| --- | --- |
| **轨道色** | 条背景 / track；与页面底色不同时必须单独采样 |
| **滑块色** | thumb / handle；与轨道色分列，禁止一个「滚动条色」糊弄 |
| **间距（几何，须进像素表）** | 条宽（或横条高）；滑块到轨道边（能测则测）；**内容区右/底到条**、**条到视口内边**分列 |

硬规则：

- `scrollbar` ≠ `slider`（数值滑条）；清单与视觉表标签用「滚动条/滑动条」。  
- 只测了列表行 / itemSpacing，却漏滚动条宽、内容→条间距、轨道/滑块色 → **报告未完成**。  
- 图上无可见滚动条 → 写「无可见滚动条」，不算漏测。  
- 未稳定读到 → 标未稳定并入【差异】，禁止猜 hex / px。  
- `layout-only`：不要求滚动条叶子。

## 按钮/可点控件圆角（强制 · 控件级）

范围内每个**可见圆角可点面**都必须测 **radius（设计 px）**，写入【视觉参数表】（或像素表同名字段），**禁止**只写卡片/面板圆角、或整页共用一个「圆角 8」。

须分列测 radius 的典型项（有则必测）：

- 主/次/文字按钮（如「重置」「停止」「确定」）  
- 同排分段粒 / 胶囊 / Chip / Tab 粒  
- 下拉触发器、网格钮（如 M1–M6）  
- 列表行内圆角输入框 / 圆角操作块（外观同按钮的可点面）  
- 其它带独立填充底的圆角可点控件

硬规则：

- **按控件短名分列**：主按钮与次按钮、胶囊与输入框、列表内框与底栏按钮圆角不同 → 必须各自一行；禁止一个笼统「圆角」。  
- 直角写 `radius 0`；全圆/胶囊写实测或「高度/2（胶囊）」并注明。  
- 只测了按钮外框/字色却漏 radius → **报告未完成**。  
- 未稳定（抗锯齿）→ 标未稳定并入【差异】，禁止猜。  
- `layout-only`：不要求控件圆角（容器外框 radius 若可见仍可测，非本门控）。

## 图标几何（强制 · 控件级）

先判断图标在图里的**源形态**，再决定测什么。  
**很多用户附图是整页/控件截图：图标已经画在毛玻璃底上，图上压根没有「独立图片外框」和透明边——这时不要编造 pad。**

### A. 独立切图资源（有透明底 PNG / 单独导出的图标）

适用于：资源本身带 alpha，或能明确框出「整张图」外沿。

必须分列（便于同形不同 pad 的复用），**报告里每个数字都必须带标签**，禁止只写「图标 24×24」：

| 字段（报告原样用这些标签） | 含义 |
| --- | --- |
| **图片实际大小 / 资源外框** W×H | 整张图文件或 Image 外接框（含透明边） |
| **墨迹大小 / 内容显示框** W×H | 可见图形外接矩形（真正画出来的大小；**不是**图片实际大小） |
| 透明边距 L/R/T/B | 资源外框到墨迹；无透明写 0 |
| 热区（若不同） | 可点区域 |

硬规则：

- 写尺寸时必须标明是 **墨迹大小** 还是 **图片实际大小（资源外框）**；二者不同时必须两行都有。  
- 禁止用「图标大小」「icon size」等含糊词同时指两者。  
- 落码/复用：对齐内容用 **墨迹大小**；对 `source` 整图用 **图片实际大小**。

自检：`图片实际宽 ≈ padL + 墨迹宽 + padR`（高同理）。对不上则重测或【差异】。

### B. 截图内嵌图标（无独立图边界 · 常见）

适用于：整页截图、卡片截图里画上去的图标；与背景融在一起，**没有**可分离的「图片边缘 / 透明区」。

只要求：

| 字段 | 含义 |
| --- | --- |
| **墨迹大小（近似）** W×H | 能圈住内容的外接盒；标签必须写「墨迹」，**不要**写成图片实际大小；不稳则标未稳定 |
| 相对父行/父卡位置或边距 | 能测则测 |
| 热区（若可点且大于墨迹） | 可分列 |
| 透明边距 | 固定写 **不适用（截图内嵌，无独立资源外框）** |

**禁止**：在 B 类上硬编 L/R/T/B，或假装量到了「到图片边缘的透明边」。  
复用说明写：「需独立透明底切图后才能测 pad；当前截图仅供位置/近似墨迹」。

### 软边 / 仍无清晰轮廓时（A、B 共用）

软边、抗锯齿、半透明、发光、与底色接近、细线：

1. 可试 alpha/对比阈值约 10–16/255，并注明阈值。  
2. 仍不稳 → 墨迹标 **未稳定读到**；B 类 pad 仍为「不适用」；A 类 pad 标未稳定。  
3. 外阴影/光晕不算墨迹。  
4. **禁止猜**精确 px 冒充实测。

### 规则摘要

- `layout-only`：不要求图标几何。  
- 控件级：每个可见图标先标 **源=独立切图|截图内嵌**，再按 A/B 填表。  
- 缺「源」分类、或 B 类却填了假 pad → 报告未完成。  
- 只有 A 类才强制完整「墨迹大小 + 图片实际大小 + 透明边距」；B 类以位置 + 墨迹近似（或不稳说明）为完成条件，且须标明是墨迹而非图片实际大小。

未稳定读到的其它视觉项同样写明，禁止猜。阴影只记备注。  
勿：外阴影当边框；**墨迹高直接当字号**（见上「字号 vs 墨迹高度」）；不采样写死色值；把墨迹大小写成图片实际大小。
