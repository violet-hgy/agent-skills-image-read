# Visual

按请求深度和提取维度分析，不默认展开全部视觉子层。
基于 structure 已建立的布局骨架逐区域分析，样式记录归属到对应容器或控件；局部识别发现分组冲突时先修正骨架。
控件组成与状态参考 [../references/controls.md](../references/controls.md)。

## 分析内容

- 容器：背景、透明度、描边、圆角、阴影、分隔线、裁剪与层级。
- 控件：尺寸等级、主次强调、填充/描边/文字型外观、图文排列、内部留白。
- 文字：标题/正文/辅助/数值等层级、对齐、换行、截断、字色、字号、字重与行高（有依据时）。
- 图标与图片：用途、显示框、墨迹、对齐、颜色或多色特征，必要时记录裁切方式。
- 状态：当前可见的选中、勾选、禁用、错误、加载、展开、焦点等状态及其视觉差异。
- 重复规则：颜色角色、间距尺度、圆角档位、排版层级；仅有重复外观证据时称候选样式规则。

## 保留语义与差异

按钮保留控件身份，可在同一记录中描述底面、文字和图标。容器不因不是叶子而丢失样式。
主/次按钮、选中/未选中项、标题/辅助文字的样式不同应分列；已证实相同的控件可共用模板。
不同控件的圆角不能被一个整页圆角概括。滚动条的轨道和滑块与数值滑条分别描述。

## 证据约束

- Figma 或其它源属性可支持具体字号、字重、变量绑定；仅从相似外观不能确认组件库或 token 名称。
- 截图可以观察排版和强调层级；墨迹高度与设计字号分开，不能直接互换。
- 抗锯齿文字、半透明底和压缩边缘的采样色，不一定等于原始设计色。精确采色时记录位置、处理方式或不确定性。
- 独立透明资源：区分资源外框、墨迹框及透明边距。
- 截图内嵌图标：透明边距与原始资源尺寸通常未知，不编造；可描述可见墨迹及位置。
- 外阴影、光晕不能当作描边或主体框；效果参数无法可靠反推时只描述可见效果。
- 只报告有证据的状态。未显示的 hover、pressed、下拉内容不按常见惯例补为事实。

只提取文案时无需进入完整样式流程；只分析骨架时无需逐字、逐图标测量。
