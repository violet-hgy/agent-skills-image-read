# Geometry

骨架分析可以只描述相对关系；请求精确尺寸、像素对齐或关键实现参数时，再按 [../gates/SKILL.md](../gates/SKILL.md) 获取测量证据。
以已有布局骨架确定测量对象、父级和参照系；数值回填对应节点，不根据孤立的尺寸记录重建布局。

## 字段按需选取

- 容器：外框、内边距、子块间距、分栏宽度、对齐与分配关系。
- 控件：布局框、内容框、内部间距；有证据时区分交互热区。
- 列表/网格：视口、行高、列宽、行列间距、首末项外距、跨行跨列。
- 浮层：面板外框、锚点、偏移、遮罩范围；面板尺寸不包含遮罩。
- 资源：显示框、可见墨迹框；只有独立资源边界可确定时才分析透明边距。

同构元素用模板参数 + 例外即可，不重复测量已证实一致的每一项。
重复项间距、首项外距、控件内 padding 分开描述。

## 坐标与单位

报告数值前标注测量来源、单位、原点和相对父对象。
截图坐标与 Figma 节点坐标分列；全局坐标和父节点局部坐标不可混用。
窗体标题栏、应用页头和内容区原点有实际影响时分别标注，不合成含糊的“顶部”。
缩放、DPR 或设计宽度未知时，像素测量只能称截图 px，不能假定为设计 px、CSS px 或逻辑像素。
有换算依据时记录公式及输入来源；截图被裁切时记录裁切偏移（如已知）。

## 精度边界

像素后端可精确读取文件尺寸或指定像素值，不代表自动识别的控件边界和设计圆角同样精确。
边界阈值、抗锯齿、阴影和压缩会影响测量，必要时记录容差或区间。
文本墨迹高度不等于字号；截图内图标墨迹不等于资源尺寸；可见框不等于点击热区。
没有测量依据的数值标为视觉推断；无法可靠确定的标未知。工具失败不以估算补齐实测列。
