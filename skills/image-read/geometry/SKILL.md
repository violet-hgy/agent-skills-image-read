# Geometry

`named-extract`：对纳入叶子测其几何类 UI 属性（文字墨迹外接、列表列宽/行高/行距、色块外框/圆角）。未纳入的类型不测。禁止因「维度=文字」跳过字号/墨迹，或因「维度=列表」跳过列宽行高。

- 原点左上；先写整图像素、**参照系（见下，禁止空写）**、**scale**（设计宽/截图宽）  
- 必测：整图边界、目标外框、padding、内容宽、border（色+宽，无则「无」）、radius、邻接 gap  
- 控件级：**每个**按钮/胶囊/下拉触发器/网格钮等圆角可点面须有**各自** radius（禁止整页一个 radius）；详见 `../visual/SKILL.md`  
- 控件级且图上可见列表滚动条：测 **条宽**、**内容→条间距**、**条→视口内边**（与 visual 的轨道/滑块色配套）；详见 `../structure/SKILL.md` `scrollbar`  
- 控件级范围内的图标：测 **墨迹 W×H** 与到图边的 **透明边距 L/R/T/B**（及资源外框）；详见 `../visual/SKILL.md`  
- 整页图加：距**内容区**右/底/左/顶（锚定边）；内容区原点见【参照系】，与整图原点不是同一点  
- 描边周缘采样；阴影≠描边  
- 禁止大画布留白当控件宽；未换算不得称设计 px  

## 参照系（强制 · 只标识坐标系）

**本包职责：** 把图上的坐标系**量清楚、标清楚**，让后续消费者不会把「整图像素」和「内容区像素」当成同一个原点。  
**本包不职责：** 不写如何改 QML / 写入哪个文件 / 用哪套 API（那是宿主落码特化 + project-bindings）。

整张位图默认原点 = 图左上（`screenshot-tl`），常含窗体标题栏或自绘标题条。其下还有应用内页头、内容区等层。这些层必须**分列测高并写入【参照系】**，禁止合成一个含糊「顶栏」。

### 【参照系】必填（原样字段）

```text
【参照系】
- 测量原点=screenshot-tl（整图左上）
- 窗体标题栏/自绘标题条=是|否 ；高度=…px（无则 0）
- 应用内页头（返回/页标题行，非上一项）=是|否 ；高度=…px（无则 0）
- 内容区原点（相对整图）=(x, y)
- 本轮几何默认相对=内容区 | 点名父控件:<短名> | 整图
```

### 图上分层（测量用 · 禁止合成）

| 层 | 图上是什么 | 必测 |
| --- | --- | --- |
| 窗体标题条 | 最小化/关闭所在条（系统或自绘） | 有则测高；写入【参照系】 |
| 应用内页头 | 返回、页标题、页级操作图标所在行 | 有则测高；与上一层分列 |
| 内容区 | 上述之下的主内容外接区 | 原点 (x,y) 相对整图；边距默认相对此层 |

### 几何数字如何标注（防误读）

【像素参数表】凡涉及位置 / 边距 /「距顶」的行，必须带 **相对=** 之一：

| 相对= | 含义（识图） |
| --- | --- |
| `整图` | 相对 `screenshot-tl` |
| `内容区` | 相对【参照系】内容区原点 |
| `父:<短名>` | 相对清单里已有父控件外框 |

硬规则：

- 缺【参照系】任一项（含高度 0 也要显式写）→ 报告未完成。`named-extract` 且维度不含几何：整节「不适用」即可。  
- 无 **相对=** 的裸 `y` / `top` /「距顶 xx」→ 报告未完成（无法区分原点）。  
- 「距顶」若未写相对，不得默认猜；应写成「距内容区顶」或「距整图顶」等可检措辞。  
- `named-subtree`：块内边距相对点名块内沿（`父:<该块>`），不要把块外标题条高度混进块内 padding 数字。  
- **禁止**在本包解释或规定如何写入代码。

工具见 `../gates/SKILL.md`。gates 未 OK 时 **禁止**本步。测图用任一准确可用后端（Python 仅为运行时，不绑定 cv2）。禁止目测估算。

多元素 / `page-layout`：按【测量范围】只测清单内项。`layout-only` 只测容器外框/分栏/gap，禁止拆内部控件。`named-extract` 只测包含树中命中维度的节点。控件级范围必须含可交互叶子，禁止只测容器外框。同排分段粒仅在控件级按 structure 测。
