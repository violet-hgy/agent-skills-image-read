# Structure

## 两个维度（先读 · 防把清单当成分区）

| 维度 | 是什么 | 不是什么 |
| --- | --- | --- |
| **布局层级**（分区树） | 谁包着谁：列 → 卡组 → 卡内行 | 不是「每个测过的外框都升一级」 |
| **清单项**（元素清单） | 要单独测的块或叶子（可有自己的高/宽） | 不等于独立一列、独立卡、一级分区 |

**规则（IF/THEN）：**

- IF 某项在清单里单独一行，THEN 只说明要测它，**THEN NOT** 新建一列 / 新建一张卡。  
- IF 某项有自己的外框（如高 94px），THEN 它仍从属于**视觉上包住它的卡组**。  
- 布局父级 = **图上的包含关系**（bbox 落在哪张卡/哪一列里），不是清单顺序，也不是「参数够不够独立」。

反例（禁止）：清单有「轴向模拟」且高=94px → 做成独立 `axisCard` / 单独一列。  
正例：一级=左列/右列；二级=左列上组、左列下组；轴向模拟 = **左列下组内部项**。

清单表必须带 **从属**（父分区路径）。从属必须指向分区树已有节点；**禁止**为清单项在树上新增列或一级分区。

## discrete-repeat（`delegate-row`）

≥2 同构近等距不相连项 → `【列表模式】discrete-repeat — N`。  
测：第1/2项 → **itemSpacing** → 首项外距 → 模板行内。外距与内距分栏，禁止一个笼统 spacing。

## dialog-sheet

遮罩 vs 面板分列；面板外框不含遮罩。

## overlay-badge

外框、border、距内容区边、内 padding。

## showcase-align

资源透明 pad + 画面墨迹；报告推导显示盒 = 资源×scale_fit（不绑定框架 API）。

## asset-compare

固有尺寸/宽高比/显示框；比例同边长不同 → 【需确认】，不擅自选定。

## page-layout 分区树（强制 · 防漏列）

【结构专表】/【可视结构】**禁止**只写到「左列/右列」就停，而只把其中一列拆到卡组。

### 必出分区树（树形，兄弟同深度）

范围内每个**列槽**必须继续拆到**可见卡组/卡片外框**（`layout-only` 也要拆到卡组，只是不拆卡内叶子）。

```text
【可视结构】
Window
├─ 顶栏
├─ 内容区
│  ├─ 左列
│  │  ├─ 上：…
│  │  └─ 下：…
│  └─ 右列
│     ├─ 上：…
│     └─ 下：…
└─ 底栏
```

【结构专表】至少含（有则必填，无则写「无」）：

| 结构项 | 结果 |
| --- | --- |
| 布局模式 | page-layout / … |
| 一级分区 | 顶栏 / 内容区 / 底栏（按实图） |
| 内容区列 | 列数 K；各列短名 |
| 列 i 子块 | **每一列一行**：该列从上到下的卡组/卡片短名（不得省略） |
| 对齐锚点 | 列顶对齐 / 底栏铺满等 |

### 对称门控（未通过 = 报告未完成）

1. 写了「左列 / 右列」（或 K≥2 列）→ **每一列**都必须有「子块」行；禁止只有「右列三级」没有「左列三级」  
2. 图上某列能看出 ≥2 个上下（或左右）独立卡片/卡组 → 该列子块必须 ≥2 个短名，禁止收成「左列功能区」一个词  
3. 分区树**末端容器**必须出现在【元素清单】（`layout-only` 到卡组外框；控件级再加叶子）  
4. 自检句（写在结构专表下，缺则未完成）：

```text
【分区对称】列数=K；各列子块数=a,b,… ；无漏列
```

K 与各列子块数对不上图 = 未完成，补树后再测几何。

## page-layout / 多元素（强制 · 受【测量范围】约束）

整页截图仍可能只测骨架或其中一块。以 classify 的【测量范围】为准。

- `layout-only`：清单只有容器行；**不要**补叶子行。  
- 其它范围：清单在范围内含第 2 层可交互叶子。

在测具体像素前，必须已有 classify 的【元素清单】。本步输出或补全：

```text
【元素清单表】
| # | 短名 | 层级 | 控件类 | 从属（父分区路径） | 必测字段 | 状态 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 左列下组 | 容器 | card | 内容区/左列 | 外框、与上组 gap | 待测→已测 |
| 1.1 | 轴向模拟 | 叶子 | segment | 内容区/左列/左列下组 | 外框、粒数、粒间 gap | 待测→已测 |
```

`控件类` 用短标签即可（不必穷尽枚举），常用：`segment`（同排分段粒）、`list-row`、`combo`、`check`/`radio`、`toggle`、`slider`、`grid-btn`、`icon-btn`、`nav-row`、`card`/`bar`。

测量顺序（强制）：

1. 内容区边距（左/右/顶/底，按锚定边）  
2. 各**容器**外框与**块间 gap**  
3. **叶子**：仅当范围不是 `layout-only` 时，对范围内容器展开并测完叶子  
4. 若范围包含顶栏/底栏：`layout-only` 只测栏外框；控件级才测分段宽/Tab 槽位  
5. 用户点名项复核  

## 可交互叶子（控件级范围才强制 · 不限胶囊）

`layout-only`：**跳过本节**。

凡 classify 在非 `layout-only` 下列出的叶子，须在本步进【元素清单表】且最终「已测」。按类最低必测：

| 控件类 | 最低必测 |
| --- | --- |
| `segment` 同排分段粒 | 粒数 N、单粒外框（或等宽推导）、粒间 gap、选中/未选中差异；**禁止**只测整条轨道当一个控件 |
| `list-row` / `nav-row` | 行外框、行高、行内间距、与上下行 gap；可复用 `discrete-repeat` |
| `combo` 下拉触发器 | 触发器外框、与标签 gap；展开面板若不在图中 →【差异】记未覆盖态，触发器仍须已测 |
| `check` / `radio` | 盒外框、与文案间距、选中态 |
| `toggle` | 开关外框、开/关态（图中可见态） |
| `slider` | 轨道、拇指、两端 ± 按钮（若有）各自外框或间距 |
| `grid-btn` | 单格外框、网格 gap、行列数 |
| `icon-btn` | 图标热区外框、相对父行边距 |

同排 ≥2 等构叶子：套用 `discrete-repeat` 纪律（测第 1/2 项 → itemSpacing → 模板），即使整图场景是 `page-layout`。

硬规则：

- **范围内**任一行仍为「待测」→ **禁止**进入 output 宣称完成  
- 控件级范围（非 `layout-only`）：仅容器已测、叶子未进表 → 报告未完成  
- `layout-only`：容器外框/分栏/gap 已测即可；**禁止**因无叶子行判未完成  
- 未测范围外叶子 **不算** 未完成  
- 可测几何不得标「猜测」；默认图为无损原图  
- 控件级任务禁止只量卡片外框就交完整报告；`layout-only` 正是只要外框
