# Classify

输出（原样标题）：

```text
【识图场景】<场景码> — <一句话依据>
【测量范围】layout-only | named-extract | full-page | named-subtree | named-control — <判定依据>
【提取目标】named-extract 必填：可视根（短名 + 外接依据）
【提取维度】named-extract 必填：本轮要取的属性（开放集合，见下）
【包含关系】named-extract 必填：目标为根的可视子树
【元素清单】N — <范围内短名…>   （N≥1；只计范围内项）
```

用户点名优先；点名项**必须**出现在【元素清单】中。

**清单 ≠ 布局层级。** 清单短名是「要测的东西」；列/卡组只来自图上的包含关系。单独测一项（甚至有独立高宽）≠ 它是单独一列或一张独立卡。从属关系在 structure 的清单表「从属」列写明。

## 主线：可视元素描述

本包读的是**图上的可视元素**，不是抽象「只要文案」字段。

1. 用包含关系拆树，直到 **基础可视元素**（图上不能再分成独立可视单元）。  
2. 容器只说明谁包谁。  
3. **到叶子后必须罗列该类型的 UI 属性**（见下；示例非穷尽）。  
4. 【提取维度】只决定**纳入哪几支叶子**（只要文字支 / 只要列表支），**不**表示文字可以不写字号、列表可以不写列宽。

### 基础可视元素与 UI 属性（开放 · 按图上实际有的写）

| 叶子类型 | UI 属性示例（有则必列） |
| --- | --- |
| 文字 | 原文、字号或墨迹高(与字号分列)、字色、字重、对齐、行数/行高 |
| 色块 / 面板面 | 外框、填色、圆角、描边 |
| 列表 | 列数、列宽、行高、行距、表头(若有)；行内再拆文字等叶子 |
| 图标 | 墨迹 W×H、色、源(切图/内嵌) |
| 图片 | 显示框、墨迹框 |

按钮等是**容器**：再拆成底面(色块) + 文字，各自列属性。禁止停在「按钮」只写一句文案。

禁止：树已到文字却只抄原文；已到列表却只抄行字、不写列宽/行高。

## 取特定元素（`named-extract` · 意图优先于图结构）

不要为「只要文字 / 只要颜色 / 只要列表」各写一条死路径。那只是【提取维度】——纳入哪类叶子。通用模型：

1. 定 **提取目标**
2. 按 **可视包含** 拆到基础可视元素
3. 用 **提取维度** 过滤纳入哪些叶子
4. 对纳入的每片叶子罗列 **UI 属性**

### 【提取目标】

用户点名的块，或附图里被当作主体的那一块（常见：裁切后的弹窗、一张卡、一条列表）。祖先（遮罩、整页）可标「范围外·只定位」，**不**当展开根。

### 【包含关系】（空间包含，不是交互角色）

以提取目标为根，子节点 = **可视外接框落在父框内**（含贴边）且图上能分开的单元。

```text
【包含关系】
panel          ← 提取目标
├─ title
├─ subtitle
└─ buttonRow
   ├─ btnCancel   （含其可见文案）
   └─ btnOK
```

规则：

- 必须罗列目标**内部**各层能分开的可视单元，并拆到基础叶子
- **禁止**罗列目标外的兄弟
- 展开深度：直到基础可视元素；再按类型列 UI 属性
- 包含关系是父树；清单是纳入的基础叶子（加必要容器短名）

### 【提取维度】（纳入哪类叶子 · 开放 · 示例非穷尽）

用户点名要看哪类元素就纳入哪类。**禁止**把下表当成唯一合法值。**禁止**用维度当借口不写叶子 UI 属性。

| 示例维度 | 纳入包含树里什么 | 叶子仍须列出的 UI 属性 |
| --- | --- | --- |
| 文字 | 目标内所有文字叶子（含按钮上的字） | 原文、字号/墨迹、字色、字重、对齐 |
| 颜色 | 目标内有独立填色/字色的面 | 该面的填色/字色（及外框若可见） |
| 列表 | 目标内的列表叶子（及行内文字） | 列宽、行高、行距；行内文字走文字属性 |
| 几何 | 目标及要对齐的框 | 外框/gap/padding |

可组合。未写明时从用户话推断（「对齐文本内容」→ 纳入文字叶子，属性含对齐）。不要默认升成整页控件级。

旧名 `text-extract` / `named-only`：一律按本档 `named-extract` 处理。

## 【测量范围】（先于清单 · 禁止见整页截图就全展开）

**图是整页 ≠ 本轮要测整页，更 ≠ 要拆到内部控件。** 先定范围，再定颗粒度。

### 怎么判定（按优先级，勿问开发「是否全图/是否拆内部」除非无法唯一框定）

0. **取特定元素** → 范围 `named-extract`（场景码常用 `named-extract`；图结构码如 dialog-sheet 可作对照，**不得**因此改成全测叶子）  
   意图：提取、只要…、对齐文案/文本内容、抄列表、取色、只要这块里的…、改 qsTr（有附图）。  
   **且不是**整页像素还原 / 只铺骨架。  
   必出【提取目标】【提取维度】【包含关系】。清单 = 纳入的基础叶子；每片须有 UI 属性。
1. **只对齐整体布局** → `layout-only`  
   意图词：整体布局、骨架、分栏、卡片位置/外框、先铺布局、只对布局、不要内部。  
   **停在容器级**：列宽、卡片外框、块间 gap、内容区边距、顶/底栏外框。  
   **禁止**展开分段粒、列表行、下拉、勾选、滑条、网格钮等叶子。  
   即使图是整页、即使说了「这一页」，只要本轮只要布局，就用本档。
2. **对话点名 / 落点（控件级）** → `named-subtree` 或 `named-control`  
   点了控件名、卡片名、底栏槽位、文件/组件，且要**还原该块整体**（不是只要其中一类内容）。范围 = 这些目标及其祖先容器（祖先只定位外框，**不**展开祖先里其它叶子）。点名块**内部**才展开叶子。  
   点名了块但只要其中文案/色/列表内容等 → **仍走档 0 `named-extract`**，不要升到本档。
3. **整页实现 / 还原内部且无「只对布局」** → `full-page`  
   如：按图还原这张首页、落地整张截图、实现配置首页（含内部控件）。
4. **切图形态**（弱信号，排在意图之后）  
   孤立单控件切图 → `named-control`。整窗截图 **不能**升为 `full-page`，也 **不能**在 `layout-only` 时拆叶子。
5. **仍无法唯一** → 【需确认】测量范围。真缺信息，不是无损原图借口。

禁止：因为 PNG 是窗体截图，就把震动、摇杆、底栏 Tab、M1–M6 全部展开。  
禁止：用户只要整体布局，却把卡片内部控件测完/落码。  
禁止：`named-extract` 漏列目标内应纳入的基础叶子，或叶子只有原文没有 UI 属性。  
禁止：`named-extract` 去测目标外兄弟。未纳入的叶子类型（如只要文字时的滚动条）不测。  
「对齐」看宾语：对齐文本/文案 → `named-extract` 维度含文案与对齐；像素对齐/按图还原/一次对齐整页 → 其它档。

### 范围内如何展开

| 范围 | 第 1 层 | 第 2 层 |
| --- | --- | --- |
| `layout-only` | 要对齐的容器 | **不展开**叶子 |
| `named-extract` | 提取目标 | 按包含关系拆到基础叶子，再列各叶子 UI 属性 |
| `full-page` | 图上全部要对齐的容器 | 每个容器内部可交互叶子都展开 |
| `named-subtree` | 点名块 + 必要时祖先外框（定位用） | **只**在点名块内部展开（整块还原时用；只要某类内容则改 `named-extract`） |
| `named-control` | 该控件外框 | 只展开该控件内部叶子（整控件还原时用） |

范围外容器：可一行「范围外·只定位」或不列入清单；**不得**因没测范围外叶子而判未完成。  
`layout-only`：没测叶子 **不算** 未完成。  
`named-extract`：漏列应纳入的基础叶子，或叶子缺该类型 UI 属性 → **未完成**；测了目标外兄弟 → **颗粒度错误（未完成）**。

## 场景表

| 场景码 | 特征 | 测量重点 |
| --- | --- | --- |
| `showcase-align` | 大块渲染常含透明边 | 透明 pad + 墨迹框 |
| `overlay-badge` | 角落浮层无遮罩 | 外框、border、页边距、内 padding |
| `dialog-sheet` | 遮罩 + 面板 | 遮罩与面板分列 |
| `asset-compare` | 新旧图比尺寸 | 固有尺寸、宽高比、显示框 |
| `control-full` | 孤立单控件切图 | 外框、padding、border |
| `delegate-row` | ≥2 同构近等距离散项 | itemSpacing + 首项外距 |
| `page-layout` | 整页 / 多区块 / 多卡片 | **先清单后逐项测**框 + gap + 距内容区边 |
| `visual-tweak` | 主要差色/字/圆角 | 视觉表 |
| `measure-only` | 只要报告 | 完整测量 + 清单 |
| `named-extract` | 取特定元素（意图优先） | 包含树 → 基础叶子 → UI 属性 |

## 强制 `page-layout`（图结构 · 不等于测量范围）

命中任一 → 场景码可用 `page-layout`（多区块测量纪律），但【测量范围】仍按点名/意图，**不要**因此全页展开叶子：

- 可独立成块的区域 ≥ 3（如主图区、卡片、底栏、侧栏）
- 整页截图 / 多卡片 + 底栏/顶栏
- 用户点名 ≥ 2 处几何对齐

判定速记：**先看意图**（取特定元素→`named-extract`；只要布局→`layout-only`）；再看图结构：透明大主体→showcase；孤立单块→control-full；≥2 同构等距→delegate-row；遮罩+面板→dialog-sheet（**仅当要还原该弹窗几何**）；角落胶囊→overlay-badge；**其余多块整页→page-layout**。  
禁止：看见弹窗截图就把场景改成 dialog-sheet 并按控件级全测叶子。取弹窗内容时场景可以记 dialog-sheet，范围必须是 `named-extract`。

## 【元素清单】规则（颗粒度随【测量范围】）

### 第 1 层 · 容器块（凡范围内都要）

卡片、面板、底栏、侧栏、弹层、列槽、**列内上下/左右卡组**。  

多列时：**每一列的卡组都要进清单**，禁止只列「左列功能区 / 右列功能区」而不写下一级卡片。`named-subtree` 时兄弟卡片不要进必测清单。`layout-only` 清单停在卡组/卡片外框，不进叶子。`named-extract` 第 1 层是提取目标，子节点走包含关系，不按列对称去拆整页。

### 第 2 层 · 可交互叶子（仅 `full-page` / `named-subtree` / `named-control`）

`full-page` / `named-subtree` / `named-control`：范围内每个要对齐的容器内，凡图上**可点击、可切换、可勾选、可展开、可拖动**，或带**独立选中/开关态**的控件，都必须进清单。

`layout-only`：**禁止**第 2 层。底栏只测整条外框，不拆 Tab 粒。  
`named-extract`：第 2 层来自【包含关系】，拆到基础叶子并写 UI 属性。按钮拆底面+文字，不要停在按钮只取字。

**判定（宽口径，不限某一视觉形态）：**

- 同排分段按钮 / 胶囊 / Chip / Tab 粒（≥2 粒）  
- **主/次/文字按钮**（控件类 `btn`；须测 **radius**，见 visual）  
- 列表行、可点导航行（如「宏功能中心 >」）  
- **列表滚动条 / 滑动条**（列表视口旁可见的竖/横条，控件类 `scrollbar`；**不是**数值滑条 `slider`）——图上看得见就必须进清单  
- 下拉 / Combo / 弹出选择触发器  
- 点选框 / 复选框 / 单选 / Radio  
- 开关 Toggle  
- 滑条及其 ± / 步进按钮（`slider`，与列表滚动条分列）  
- 网格内独立按钮（如 M1–M6）  
- 单元格或行内的独立图标按钮  
- **可见图标**（装饰或可点）：进清单为 `icon` / `icon-btn`，须测 **墨迹 W×H + 透明边距 L/R/T/B**（见 visual）

以上为**典型例**，不穷尽；形态叫「胶囊」与否不重要，**交互叶子**才重要。仅适用于控件级范围（`full-page` / `named-subtree` / `named-control`）。

**禁止：**

- 控件级任务只写「震动卡」却不列其内分段粒、滑条、开关等  
- **测了列表行却漏掉图上可见的滚动条**（色、宽、与内容/容器边距）  
- **测了按钮外框/文案却漏 radius**（禁止整页一个圆角冒充各按钮）  
- 把整排分段控件当成「一条背景」而不拆叶子（`layout-only` 除外；`named-extract` 纳入列表则必须拆行并写列宽/行高）  
- 以“子控件另写可选”为由跳过控件级任务的第 2 层  
- 部分控件任务却把整页叶子测完  
- **只要整体布局却展开内部各个控件**  
- **`named-extract` 漏基础叶子、或文字/列表叶子没有 UI 属性、或把目标外兄弟测进来**

纯展示文案/只读标签：控件级任务可不单独成行；**`named-extract` 纳入的文字必须成行并写 UI 属性**。

范围内禁止漏点名块；仅当底栏/角标在范围内才必须列入（`layout-only` 列入栏外框即可）。  
默认**无损原图**：不得以信息不足少列范围内应测项或要求开发二次确认。

仅当测量目标**无法唯一框定**时停问；可测几何不得标成需确认。
